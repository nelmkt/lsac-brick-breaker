# Bug Breaker

**An LSAC (Learn Student Ambassadors Club) event project**

A small browser game for our club events. Break the tech topic bricks, squash the bugs, and learn a quick tip each time.

**Play now:** https://nelmkt.github.io/lsac-brick-breaker/

## How to play
- Move the paddle with the arrow keys or your mouse
- Bounce the ball into the bricks to break them
- Each topic brick (Cloud, Code, Data, AI, Security) gives points and a tech tip
- Bug bricks take two hits
- Clear all the bricks to level up, and the ball gets faster
- Don't let the ball fall, you only have 3 lives

## Source code
This game is based on the open-source **2D Breakout game** from MDN's
"2D breakout game using pure JavaScript" tutorial, by Andrzej Mazur and Mozilla contributors:

- Original code: https://github.com/end3r/Gamedev-Canvas-workshop (`lesson10.html`)
- Tutorial: https://developer.mozilla.org/en-US/docs/Games/Tutorials/2D_Breakout_game_pure_JavaScript

The original code samples are dedicated to the public domain (CC0). See `LICENSE-ORIGINAL.txt`.
The first commit in this repo is the original game, and every change after that is our club's work.
