# Bug Breaker

A mini game for LSAC (Learn Student Ambassadors Club) events. Break the tech topic bricks, squash the bugs, and pick up a tech tip along the way.

**Play:** https://nelmkt.github.io/lsac-brick-breaker/

## How to play
Move the paddle with the arrow keys or mouse. Bug bricks take two hits. Clear all the bricks to level up.

## Credits
Based on MDN's open-source [2D Breakout game](https://developer.mozilla.org/en-US/docs/Games/Tutorials/2D_Breakout_game_pure_JavaScript) by Andrzej Mazur and Mozilla contributors ([source](https://github.com/end3r/Gamedev-Canvas-workshop), public domain).
