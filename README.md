# Bug Breaker

A mini game for LSAC (Learn Student Ambassadors Club) events. Made by the tech department for the whole club and FCIT students. Break the bricks, squash the bugs, and see how many levels you can clear.

**Play:** https://nelmkt.github.io/lsac-brick-breaker/

## How to play
Move the paddle with the arrow keys or mouse. Bug bricks take two hits. Clear all the bricks to level up.
